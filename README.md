# Aragonite Vault — téléchargements

Paquets publiés d'Aragonite Vault, le gestionnaire de mots de passe chiffré de bout en bout d'Aragonite :
application Linux (.deb, .rpm, AppImage), application Android (.apk) et extensions Chrome / Firefox.

- Installer : onglet « Installer » de https://pass.aragonite.fr
- Nouveautés de chaque version : https://updates.aragonite.fr/#vault

Le code source n'est pas dans ce dépôt. Chaque release contient `SHA256SUMS.txt`.
